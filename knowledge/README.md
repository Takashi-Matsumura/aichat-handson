# 知識ソース(RAG用資料)の置き方

このフォルダに `.md` または `.txt` ファイルを置くと、チャットのRAG機能が
自動でその内容を読み込み、検索できるようにします。**この README 自体は
検索対象になりません。**

## 使い方

1. 資料ファイル(`.md` / `.txt`)をこのフォルダに置く(サブフォルダに置いてもOK、
   日本語ファイル名もOK)
2. チャット画面で「RAG」トグルをONにして質問する
3. 次の質問から自動で反映されます(数秒かかる場合があります)。すぐに反映させたい
   場合は `/presenter` の「知識ソースを再読み込み」ボタンを押してください

## 資料の書き方のコツ

- 1ファイル1テーマにすると検索精度が上がります
- `#` 見出しで章立てすると、見出し単位でチャンク分割されるため検索がヒットしやすくなります
- 目安として、合計で数十〜数百KB程度までにしてください(全チャンクをメモリ上に
  保持して検索するため)

## デモとして見せる場合のコツ

「AIが元々知らないはずの、社内固有の事実」を1行入れておくと、RAGをOFF→ONに
切り替えたときの違いがはっきり分かります。例:

```markdown
# 経費精算マニュアル

## 締切と例外

当社の経費精算の締切は毎月7日です。7日を過ぎた申請は翌月扱いになります。
```

## 注意

- 個人情報・機密情報は置かないでください。ここに置いた内容はそのままAIへの
  プロンプトに含まれます
