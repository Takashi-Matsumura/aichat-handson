# 研修用サンプル資料（RAG）

ハンズオンテキスト「AIと社内資料（RAG）」の演習で使う、架空の会社「株式会社ハンズオン工房」の社内規程です。
実在の企業・人物とは関係ありません。

## 使い方

`knowledge/` フォルダにコピーすると、RAGの検索対象になります。

```bash
cp samples/knowledge/0*.md knowledge/
```

コピーしたあと、`/presenter` の「RAGソース」タブで「知識ソースを再読み込み」を押すと、すぐに反映されます
（押さなくても、次の質問のときに自動で読み込まれます）。埋め込みサーバが起動している必要があります。

テキストの演習は、次の内容が資料に書かれている前提です。資料を書き換えるときは、テキスト（`public/handson/handson6.md`）も合わせて直してください。

| 演習 | 資料の記載 |
|---|---|
| リモートワーク手当 | `02_就業規則_勤務時間.md`：月額3,000円 |
| 誕生日休暇の申請期限（続けての質問） | `03_休暇規程.md`：誕生日休暇は特別休暇、特別休暇は2週間前までに申請 |
| 出張の日当と宿泊費（計算） | `04_経費精算規程.md`：宿泊出張の日当1日3,000円、東京23区の宿泊費上限1泊14,000円（1泊2日なら合計20,000円） |
| 社員食堂の営業時間 | どの資料にも書かれていない（「記載がありません」が正解） |
| 情報の分類 | `05_情報セキュリティ規程.md`：極秘・社外秘・公開の3段階 |
